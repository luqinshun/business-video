# 商业知识类中长视频制作指南

面向 B 站商业知识、商业故事、公司分析、消费观察及 AI 商业内容的研究报告与制作标准。默认适用于中文、横屏、8—30 分钟视频，重点解决选题、口播、前三分钟开场、画面、音效、背景音乐，以及整片的持续观看体验。

**当前版本：V1.0 · 研究日期：2026 年 11 月 22 日。**

## 如何使用

1. **策划立项：** 明确主问题、目标观众、观众收获与核心证据，填写报告末尾的启动表。
2. **包装与开场：** 统一标题、封面和第一句话的承诺，设计至少两版开场，明确前一分钟交付什么知识。
3. **脚本与分镜：** 同时设计口播、证据、画面和声音；每一章都应带来新的认识。
4. **制作与审校：** 按执行标准检查事实、数字、图表、字幕、人声、音乐和素材许可。
5. **试读与试映：** 检查观众能否理解主问题、复述关键解释，以及开场承诺是否兑现。
6. **发布与复盘：** 在相近题材、时长、观众来源和观察窗口下比较表现，用实际反馈修订标准。

首次使用建议完整阅读研究报告；日常制作优先使用执行标准，需要方法解释和案例时返回报告。

## 前三分钟的默认设计

下表是可调整的内部制作起点，详见报告第 5 节与第 13 节。

| 时间 | 应完成的任务 |
| --- | --- |
| 0—10 秒 | 用具体对象、结果或矛盾建立关注点 |
| 10—30 秒 | 说清核心问题，以及观众为什么值得继续看 |
| 30—60 秒 | 交付第一条真实证据、解释或可复算的例子 |
| 60—90 秒 | 讲明一个关键因果关系 |
| 90—120 秒 | 用模型或图示解释变化 |
| 120—150 秒 | 引入新条件、反例或适用边界 |
| 150—180 秒 | 给出阶段答案，再进入下一项具体问题 |

开场应持续提供知识回报。后续观看动力来自更深入的解释、条件变化与判断能力，而不是把所有答案延迟到结尾。

## 研究报告覆盖内容

- 研究结论、证据边界与 7 个 B 站公开案例。
- 商业选题、标题封面、开场与整片叙事结构。
- 中文口播、商业论证、图表、动画与字幕。
- 人声、音效、背景音乐与混音建议。
- 制作流程、交付格式、质量验收与发布后复盘。
- 一套完整的前三分钟示范：咖啡店发优惠券后，为什么卖得更多却可能亏钱。
- 27 项可复核来源，以及每期启动表。

## 证据与适用范围

报告分别标明平台官方说明、公开案例、创作者经验、学习研究和本项目的编辑建议。案例播放数是研究时检索可见的快照；没有相关视频的创作者后台留存数据。

文中的秒数、语速、音频参数、评分与复盘周期是内部起点，不是 B 站算法规则，也不保证爆款或完播。咖啡店开场示范使用教学假设，不能作为真实品牌经营数据引用。完整来源和具体限制见研究报告。

## 后续维护

后续视频默认按本仓库的执行标准推进。若实际作品的试映或后台数据支持调整，应记录修改理由、适用条件和版本日期，再更新标准；不要把单条视频的表现直接推广为通用规律。
