# 商业知识视频设计

把具体选题转成能执行、能核查、能迭代的视频方案。让观众持续获得理解与判断能力，在结尾得到开场承诺的答案。

## 1. 读取标准，确认范围

- 先读 [制作执行标准](references/production-standard.md)，遵守其中的项目质量要求。用户本次要求优先；秒数、语速、字号、响度和评分是可调整的内部起点。
- 完整设计时，读取并填充 [每期制作模板](assets/episode-design-template.md)。局部修改时仅用相应部分，不强制交付整套材料。
- 需要研究依据、案例、音画方法或示范时，按下表读取 [研究报告](references/research-guide.md) 的相关章节，避免每次加载全文。报告基线为 2026-11-22 的 V1.0；新的事实与平台功能另行核验。

| 本次问题 | 报告章节 |
| --- | --- |
| 证据可靠性、公开案例 | 1—2、14 |
| 选题、标题封面 | 3—4 |
| 开场、持续观看与叙事 | 5—6、13 |
| 中文口播、商业论证 | 7 |
| 画面、图表、动画、字幕 | 8 |
| 人声、音效、背景音乐 | 9 |
| 交付、验收、复盘 | 10—12、附录 |

沿用已有选题、定稿、素材和用户修订；“继续”表示推进当前任务。新任务缺少非关键背景时，明确合理假设后继续。只有主题本身或关键约束缺失、无法合理假设时，提出一个简短问题。

未指定时，采用：B 站、16:9、中文、约 12 分钟；面向对商业与 AI 感兴趣的普通观众；以配音和解释性动画为主，不依赖真人出镜；表达清楚、自然，允许少量服务主题的幽默。说明这些是本次设计假设，允许用户覆盖。

## 2. 选择交付模式

| 用户意图 | 本次交付 |
| --- | --- |
| 研究选题或主题系列 | 观众与主问题、选题方向、证据、差异、可视化潜力、推荐理由 |
| 完整视频设计 | 完成下述流程及制作模板，包含全片连续口播；不要停在提纲 |
| 开场太弱、改前 N 秒 | 两到三种不同入口、推荐理由、选定版完整 N 秒口播及音画分镜；保留已确认正文 |
| 优化已有稿件 | 修订稿、关键改动及目的、必要的事实纠错；按要求控制范围 |
| 只做动画分镜或声音 | 根据确认口播输出可执行的镜头或声音表，标明缺失素材 |
| 审核成片或分析留存 | 先确认实际取得的视频、音频、字幕或数据，给出问题位置、优先级与验证办法 |

用户指定短视频或竖屏时，重新预算“问题—证据—解释—条件—收束”；不要塞入三分钟开场，不机械套用长视频章节数。

## 3. 明确观众收益，核验证据

写清主问题、目标观众、已有认识、看完后的判断能力、核心主张与适用范围。每期围绕一个主问题，章节分别回答必要的子问题。

对真实公司、人物、价格、近期事件、论文、产品功能与平台规则重新检索核验。优先原始论文、官方文档、公司披露、原始采访和直接数据；区分事件、发表和查阅日期。用户要求仅用给定材料或纯教学模型时遵守该范围，不把假设包装成真实调查。

用本期独立编号 E01、E02 建立证据台账：具体主张、事实身份、来源与日期、支持范围、反证或其他解释、使用位置、核验状态。区分“已核实事实、作者解释、教学假设、预测、尚待核实”。标题和结论只承诺证据实际支持的内容。

为重要判断寻找反例。来源冲突时比较时间、定义、样本与口径。缺少证据时收窄说法或标明待核验，不捏造引用、数字、台词、实验结果和链接。

独立复算模型和图表，核对单位、币种、期间、分母、含税及折扣口径。区分营收、GMV、利润、现金流、估值和融资到账；区分单位贡献与完整净利润。AI 主题还要核对任务、模型版本、基准和成本口径，不把演示能力直接推广为稳定商用能力。

## 4. 设计一致的包装与开场

完整设计先给三组标题封面方向，再推荐一组；写清承诺、主体构图、封面短文案与正文兑现位置。避免编造比例、绝对化排名和无法兑现的结果。

至少提供两种不同的 0—30 秒开场入口，重要主题提供三种；选定后写完整前三分钟。局部任务按用户指定的时间范围处理。可选入口：

- **结果矛盾：** 展示具体结果与常见理解的冲突，再追问缺失的变量。
- **观众决策：** 给出有代价的选择，用证据帮助观众修正判断。
- **证据演算：** 从账单、原始材料、可复算数字或小实验得到一个意外结果。

不同版本改变叙事入口，不能只换形容词。前 3 秒安排能辨认的对象、动作或反差，以及自然首句的起始部分；不要为塞入整句话而超速。幽默来自具体情境，不用无关笑话、固定网梗或他人的标志性台词。

| 时间预算 | 编辑任务 |
| --- | --- |
| 0—10 秒 | 对象、矛盾与首画面一致 |
| 10—30 秒 | 主问题与观众收益明确 |
| 30—60 秒 | 交付第一条真实证据、解释或可复算例子 |
| 60—90 秒 | 解释一条因果关系 |
| 90—120 秒 | 用第一层模型解释现象 |
| 120—150 秒 | 用条件变化、反例或新证据深化理解 |
| 150—180 秒 | 给阶段答案，再进入下一个具体问题 |

按内容调整时间。检查：30 秒是否知道讲什么；1 分钟是否已有收获；3 分钟继续看能获得什么。不要用“看到最后才揭晓”替代解释，不让前三分钟变成重复预告。

## 5. 建立持续推进的全片结构

优先用“现象—常见解释—证据与机制—条件变化—选择与代价—可迁移判断”组织内容，按题材调整。每章列出问题、新认识、证据、视觉模型与下章承接。

约每 60—90 秒检查有无信息进展，不要求固定频率反转、切镜或换音乐。用阶段答案带出更具体的问题，及时兑现悬念。结尾回答主问题，交付少量判断条件和一个相关互动问题；关注提示放在知识交付之后。

## 6. 写完整、自然、可试读的中文口播

讲清谁做了什么、为什么、代价是什么。一个句子承担一个主要关系；先举例再命名陌生术语。用“问题—事实—解释—小结”推进段落，避免抽象名词堆积、空泛金句和机械转折。

按有效口播时间预算：普通解释可先试 230—280 汉字/分钟，密集数字与陌生概念 180—230；从总时长扣除看图、停顿、采访与现场声，展开数字、缩写和符号的朗读。这些仅是内部起点。

完整视频必须有覆盖全部章节的连续口播，并把选定开场纳入正文。检查真实稿件长度与目标时长是否相称，不能把数百字提纲标成十几分钟完整稿。局部任务交付所要求范围的完整稿。

实际配音或试读后再校准时间码；未试读一律写“预计/编排预算”。不捏造已试读、实测时长或成片效果。

## 7. 同步设计画面、动画与声音

让每个主要画面承担证据、机制解释、对比或场景定位的任务。写清对象、动作、出现顺序、关系与素材来源，不只写“高级动画”“快节奏剪辑”。优先可复算账本、资金流、稳定角色关系、真实文档定位及逐步展开的图表。

固定主体颜色、位置和称谓，箭头标含义。图表注明单位、时期、估算与来源；柱图和面积图用零基线，折线截轴清楚标示。中央画面只呈现当前重点，字幕保留准确语言；用手机尺寸检查遮挡与可读性。

每个镜头记录：预计时间和镜号、口播、问题与认知收获、证据编号和事实身份、画面动作及素材、屏幕文字和图表口径、音乐音效及停顿、许可状态、下段承接。前三分钟细化到能排动画，后续也覆盖完整音画逻辑。

先保证只听人声也能理解，再加音乐和音效。说明音乐功能、进入退出位置、降低或撤掉的位置；复杂算账、关键限定和反例允许无音乐。不要求每次切镜都加音效，也不按固定间隔换曲。

录音与混音从执行标准参数起步，明确不是 B 站官方要求。未选具体曲目时交付风格、功能与许可需求；实际核验授权后才能标“已确认”。AI 画面不得冒充真实文件、现场、当事人发言或实验结果。

## 8. 交付可直接使用的结果

完整设计按制作模板交付六组材料：

1. **立项与研究：** 主问题、观众、收益、范围、证据、反例与待核验项。
2. **包装与开场：** 三组标题封面、两到三种入口、推荐理由与选定前三分钟设计。
3. **结构与口播：** 全片章节、新认识、连续完整口播、字数和时长预算、试读状态。
4. **音画制作：** 全片分镜、动画、屏幕文字、素材表、配乐音效表及许可状态。
5. **发布资料：** 字幕文本、简介、来源、章节和互动问题；未配音时只能提供估时字幕或文本。
6. **验收与复盘：** 实际已做和未做的检查、优先修改项、本期一个优先验证的制作假设。

准确区分“方案/素材/成片”“预计/实测”“许可待核验/已核验”“试映计划/已试映”。不声称生成未生成的音频、图片、动画或视频。用户要求实际制作时，使用适当技能与工具延续本设计。

按用户要求交付文件，遵守当前会话授权和相应工具规范。不要把每次设计自动发布到外部平台，也不要自动改写本 Skill；用户要求更新标准时再记录依据并保存版本。

## 9. 根据实际材料验收

先修复事实、算账、承诺、图表以及实际发现的听辨问题；成片发布前确认素材许可。评分不能抵消这些问题；未实际执行的检查不能标通过。

有成片时检查只听声音、静音看图、手机外放与完整观看；没有成片时交付待执行清单。用观众能否复述问题、解释和边界检验理解，小样本反馈不宣称统计胜出。

留存复盘仅使用实际提供或获授权获取的后台数据，记录指标定义、时间窗、片长、受众与流量来源。区分平均播放进度与完整看完人数比例；峰值可能表示难懂，低谷可能表示跳过或退出。曲线解释写成待验证假设，不能伪装为因果证明。

保持证据边界：播放量不能反推完播率；创作者经验不是推荐算法；学习研究不能承诺流量；未查看原视频时不编造逐秒画面、配乐听感或观看经历。不承诺爆款、通用完播阈值或固定提升幅度。
