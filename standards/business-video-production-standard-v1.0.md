# 商业知识视频制作执行标准 V1.0

制定日期：2026年11月22日。

本文件用于后续商业知识、商业故事、公司分析、消费观察及AI商业中长视频的策划、写稿、分镜与验收。主要平台为B站，默认中文、横屏、8—30分钟。更短视频、访谈或纪录片按内容调整。与《商业知识类中长视频制作指南》配套使用。

## 一 核心目标

让目标观众愿意点进来、持续理解、获得可复用的判断能力，并在结尾得到开场承诺的答案。观看时长与理解都要检查。

以下“必须”是本项目质量要求。秒数、语速、音频参数、评分与复盘周期是内部起点，后续用实际作品反馈校准，不称为B站算法规则，不保证爆款。

## 二 必须遵守的要求

1. 每期一个明确主问题，写清目标观众、原有认识、预期收获与适用范围。
2. 先研究再确定结论。核心事实有可复核来源，重大判断查找反例与其他解释。
3. 区分事实、作者解释、教学假设与预测。不捏造数字、人物台词、后台留存、观看经历或参考文献。
4. 标题、封面、第一句话和正文共同兑现同一个承诺。
5. 开场直接进入具体问题；前三分钟已经持续提供知识回报。
6. 研究、口播与画面并行设计。每个关键段落有相应的证据或解释画面。
7. 故事以因果和选择推进，每章带来新认识。重要悬念有明确兑现位置。
8. 中文口播自然、主语明确、因果清楚；先举例再命名陌生概念。
9. 图表不误导；数字的单位、时间、地区、币种、分母和统计口径一致。
10. 人声清晰优先。音乐和音效有具体功能，复杂推导允许无音乐。
11. 完整字幕准确同步。AI示意与真实证据分清，素材许可有记录。
12. 发布前做试读与试映，发布后按相近时长、题材、观众来源和观察窗复盘。

## 三 每期立项卡

- 主问题：为什么某个明确对象在给定条件下出现某种结果，或为什么做某个选择？
- 目标观众：谁会关心；他们现在可能怎么理解？
- 观众回报：看完能多做出什么具体判断？
- 一句核心主张：本片准备论证什么；哪些条件下成立？
- 三项核心证据：原始来源、日期、原文位置与支持范围。
- 不利证据或另一种解释：它是否要求我们修改结论？
- 时长与范围：哪些内容必要，哪些留到后续？
- 可视化：能否用账本、角色关系、时间轴或真实物品解释？

可用内部评分：证据25、观众关联20、解释空间15、主线集中15、可视化15、系列价值10。每项按0、半分、满分评估；总分75且证据至少15作为初始立项参考。评分不预测流量。

## 四 包装与开场

至少提交两版开场，重要主题三版：结果矛盾型、观众决策型、证据演算型。三个版本要改变叙事入口，不能只换形容词。

第一屏出现具体对象或关键动作。第一句话不使用无关问候、履历、长Logo片头或泛泛震惊。幽默可以有，但应帮助理解主问题。

### 默认前三分钟

| 时间 | 必须完成的内容 |
| --- | --- |
| 0—10秒 | 对象和矛盾清楚，首画面对应第一句话 |
| 10—30秒 | 主问题与观众收益明确，兑现标题封面期待 |
| 30—60秒 | 用一项证据或小例子交付第一个实际收获 |
| 60—90秒 | 解释一条因果关系，画面逐步增加必要信息 |
| 90—120秒 | 让观众能够使用第一层模型解释现象 |
| 120—150秒 | 通过新条件、反例或证据深化理解 |
| 150—180秒 | 给阶段答案，再自然提出值得继续的问题 |

这些时间可根据内容调整。教程可以更早直接给答案，故事可以先给具体情境，但不能让前三分钟全是预告。三个关键检查问题：30秒知道讲什么吗；1分钟已学到什么；3分钟为什么还值得继续？

## 五 全片叙事

优先采用：现象与矛盾 → 常见解释 → 机制与证据 → 条件变化或反例 → 决策与代价 → 适用边界 → 可迁移判断。

每约60—90秒检查是否有信息进展。这是编辑检查间隔，不是强制反转或切镜频率。复杂图可停留更久，情节推进可更快。

每章都回答不同的子问题。结尾回收开头的问题，再交付少量判断条件和一个具体互动问题。不要提前反复释放“已经讲完”的信号，不用空泛求三连打断关键解释。

## 六 口播标准

- 讲清谁做了什么、为什么、付出什么代价；不只堆抽象名词。
- 一个句子承担一个主要关系。术语先用例子说明，再给名称。
- 每段尽量组织成：小问题、具体事实、关系解释、阶段结论。
- 初始预算为普通解释230—280汉字/分钟，数字与陌生概念180—230；以真人或实际配音试读为准。
- 总字数按真实口播时间计算，扣除看图、停顿、采访和现场声。数字与缩写展开朗读。
- 幽默以共同经历、轻微反差和回扣为主，不能替代证据，不能强行模仿他人标志性表达。
- 核对营收、GMV、利润、现金流、估值、融资到账和增长口径，不能混用。

## 七 画面与分镜标准

每个主要画面至少承担证据、机制解释、对比或场景定位的一项任务。优先用真实原始材料、可复算账本、资金流和逐步生长的角色图；不要只给旁白贴无关素材。

同一主体保持稳定颜色、位置和称谓。动画讲到哪里出现哪里，关系箭头标明含义。柱图与面积图以零为基线，折线截轴需清晰标示；比较尺度一致，估算和情景清楚区分。

图表显示关键指标、单位、时期和短来源；简介保存完整链接。财报截图先定位原文，再转简图解释。字幕区保留准确语言，中央画面只呈现当前重点，避免重复大段口播。

1080p横屏字幕可从44—56像素、最多两行试起，按字体和手机实际预览调整。检查弹幕、按钮和画面边缘遮挡。AI生成画面不能充当真实文件、新闻现场或企业发言证据。

每段分镜固定字段：

1. 时间段与镜号。
2. 口播。
3. 当前回答的问题与认知收获。
4. 证据编号、来源与事实身份。
5. 画面动作与素材。
6. 屏幕文字与字幕重点。
7. 配乐、音效及降低或撤掉音乐的位置。
8. 接入下一段的逻辑。

## 八 声音标准

先完成只听人声也能理解的版本，再加音乐和音效。分开保留人声、音乐、音效与环境声。录音问题优先重录，避免过度降噪和压缩。

| 项目 | 内部起点与说明 |
| --- | --- |
| 人声录制 | 48kHz、24bit；保留无损原声 |
| 录音峰值 | 约−12至−6dBFS，保留大声余量 |
| 成片综合响度 | −16±1 LUFS-I，测全片最终混音导出文件 |
| 最大真峰值 | ≤−1dBTP，复核有损编码后的文件 |
| 音乐避让 | 相对已设置好的无对白音乐基线，可先试6—12dB，再逐句人工调整 |

上述不是B站官方强制标准。不要把轨道推子值当成人声与音乐的真实响度差，也不要为达响度数字把人声压扁。

开场让第一句话听清；故事推进可用稳定节奏；复杂算账和限定条件降低音乐或无音乐；发现结论可以短暂留白；解释反例用中性声音；总结温和收束。每个切镜头不必加音效，一首音乐也不必按固定秒数更换。

每首音乐和音效记录作者、原始链接、取得日期、许可版本、适用平台、商业范围及署名。YouTube可用、免费或免版税均不能自动当作所有平台所有用途的授权。

## 九 每期交付清单

1. 选题说明与目标观众。
2. 三组标题封面方向及推荐理由。
3. 两到三版开场，以及完整的前三分钟定稿。
4. 全片章节结构，每章写明新认识。
5. 完整口播稿与实际试读时长。
6. 分镜、动画要求、屏幕文字和素材清单。
7. 配乐音效表与许可记录。
8. 事实核查、来源台账、不同解释与适用条件。
9. 字幕、发布简介、章节时间、具体互动问题。
10. 验收清单及本期唯一优先验证的制作假设。

## 十 验收与复盘

核心事实、承诺一致性、人声清晰、图表准确先通过；素材与音乐许可须确认覆盖计划发布平台和使用方式并留存记录。随后再评分。内部权重：选题承诺15、前三分钟25、证据论证20、口播结构15、画面15、声音10；80分为初始发布参考，不能掩盖关键错误。

四遍检查：只听音频；静音看图；手机小屏外放；正常完整观看。可找5—8位目标观众试映，查看他们能否复述问题、收获与边界，并指出离开的时间及原因。小样本不宣称统计胜出。

发布后先按72小时、7天固定观察窗记录；长尾内容增加28天。记录后台实际提供的关键节点、平均观看、平均进度、来源与受众、关注及理解反馈，缺失字段标未提供。

回看高峰可能是精彩，也可能是难懂。低谷可能是跳过或退出。每8—10条可比视频复盘一次；每轮优先验证一个改动。手动前后换封面、不同题材或不同流量的视频比较只能提供方向性证据。
